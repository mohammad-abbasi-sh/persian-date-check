# persian-date-check — بررسی تاریخ‌های شمسی در متن فارسی

**ممیزی متن فارسی برای تاریخ‌های شمسیِ اشتباه — لایه‌ای که مبدل جلالی ندارد.**

ایجنت‌هایی که محتوای فارسی می‌نویسند، مدام تاریخ شمسی می‌آورند — و
مدام اشتباه می‌آورند. خطای کلاسیک، روز هفته است: ایجنت می‌نویسد
«جمعه ۲۱ آبان ۱۴۰۵» در حالی که ۲۱ آبان ۱۴۰۵ پنجشنبه است. کسی متوجه
نمی‌شود، چون جمله درست خوانده می‌شود و هیچ بیلدی خراب نمی‌شود. همین
اتفاق برای تاریخ‌های ناممکن («۳۱ آبان»، «۳۰ اسفند» در سال غیرکبیسه)
و برای جفت‌های شمسی/میلادی می‌افتد که یک طرفشان اشتباه کپی شده
(«۲۰ آبان ۱۴۰۵ برابر با ۱۲ نوامبر ۲۰۲۶» — در حالی که ۱۱ نوامبر است).

مبدل‌ها هیچ‌کدام از این‌ها را نمی‌گیرند. parsi-mcp با ۵۶ ابزار،
persian-text-skill، jalali-moment و PersianDate هر تاریخی را که به
دستشان بدهید تبدیل می‌کنند — اما هیچ‌کدام پاراگراف شما را نمی‌خوانند
و نمی‌پرسند تاریخی که در آن است، درست است یا نه. این اسکیل همان لایهٔ
ممیزی است؛ مکمل مبدل‌ها، نه جایگزین آن‌ها.

## چه چیزی را بررسی می‌کند

| کد | بررسی | مثال |
|------|-------|---------|
| PDC-01 | تاریخ ناممکن | ۳۱ آبان (۳۰ روزه)؛ ۳۰ اسفند ۱۴۰۴ (سال کبیسه نیست) |
| PDC-02 | روز هفتهٔ اشتباه | «جمعه ۲۱ آبان ۱۴۰۵» — ۲۱ آبان پنجشنبه است |
| PDC-03 | جفت شمسی/میلادی ناسازگار | ۲۰ آبان ۱۴۰۵ ≠ ۱۲ نوامبر ۲۰۲۶ (۱۱ نوامبر است) |
| PDC-04 | تاریخ نسبی در برابر مطلق | «فردا ۲۲ آبان» در ۲۰ آبان (فردا ۲۱ آبان است) |
| PDC-05 | قاطی‌شدن ارقام در یک تاریخ | «۲1 آبان ۱۴۰۵» |
| PDC-06 | ارقام عربی (٠-٩) در متن فارسی | «٢١ آبان ١٤٠٥» |
| PDC-07 | سال نامحتمل | سال شمسی خارج از ۱۳۰۰–۱۵۰۰ |
| PDC-08 | غلط املایی نام ماه | «ابان» به‌جای «آبان» |

## قبل / بعد

```text
$ python3 scripts/persian_date_check.py check article.md

[ERROR] PDC-02 line 1: Wrong weekday: "جمعه ۲۱ آبان ۱۴۰۵" says جمعه, but that date is پنجشنبه
[ERROR] PDC-01 line 3: Impossible date: "۳۱ آبان ۱۴۰۵" — day 31 does not exist
      آبان ۱۴۰۵ has 30 days
3 error(s), 0 warning(s).
```

اصلاح مکانیکی، بعد اثبات:

```bash
python3 scripts/persian_date_check.py check article.md --fix   # writes article.md.fixed
python3 scripts/persian_date_check.py check article.md.fixed   # تا exit 0
```

## نصب

**Claude Code / Claude.ai** — پوشهٔ اسکیل را کپی کنید یا فایل
`dist/persian-date-check-skill.zip` را آپلود کنید:

```bash
cp -r skills/persian-date-check ~/.claude/skills/
```

**Cursor** — فایل `cursor/persian-date-check.mdc` را در
`.cursor/rules/` پروژه بگذارید (برای Windsurf و Cline و Continue به
`cursor/README.md` نگاه کنید).

**MCP (هر کلاینت)** — سرور stdio در `mcp-server/` سه ابزار دارد:
`check_persian_dates` (متن یا فایل)، `convert_date`
(to-jalali / to-gregorian) و `today`.

**استفادهٔ مستقیم** — بدون نصب و بدون وابستگی (فقط Python 3.9+ و
stdlib):

```bash
python3 skills/persian-date-check/scripts/persian_date_check.py check article.md
python3 skills/persian-date-check/scripts/persian_date_check.py convert to-jalali 2026-11-11
python3 skills/persian-date-check/scripts/persian_date_check.py convert today
```

## راستی‌آزمایی (بدون ادعای آماری بدون اجرا)

- **۷۱ تست پاس می‌شود** (`pytest tests/`): انکرهای تبدیل در برابر
  jdatetime، رفت‌وبرگشت تمام روزهای بازهٔ پشتیبانی، هر کد بررسی،
  فیکسچرهای سرتاسری، رفت‌وبرگشت `--fix`، کدهای خروج CLI، خروجی
  JSON و تست سرتاسری MCP.
- **تبدیل در برابر jdatetime روی ۷۳٬۴۱۴ روز شمسی** (۱ فروردین ۱۳۰۰ تا
  ۲۹ اسفند ۱۵۰۰) با **۰ اختلاف**، و ۷۳٬۰۵۰ روز میلادی با ۰ اختلاف.
  سال‌های کبیسه در ۱۳۰۰–۱۵۰۰ یکسان‌اند.
- مبدل، پیاده‌سازی از صفر با stdlib از روش breaks بورکوفسکی است —
  در زمان اجرا هیچ کتابخانهٔ تاریخی استفاده نمی‌شود.

## چه کاری نمی‌کند

- تاریخ را برای نمایش تبدیل نمی‌کند (برای آن از مبدل استفاده کنید).
- تعطیلات را نمی‌شناسد — تعطیلات ایران دیتاست جداگانه‌ای است.
- تاریخ‌های لفظی («بیست و یکم آبان») را پارس نمی‌کند.
- تاریخ نسبی فقط وقتی بررسی می‌شود که تاریخ مطلق در همان جمله باشد.

برای استدلال کامل به
`skills/persian-date-check/references/date-rules.md` و برای مثال‌های
قبل/بعد به `skills/persian-date-check/references/examples.md` نگاه کنید.

## نقشهٔ راه

- دیتاست تعطیلات (اول تعطیلات ثابت خورشیدی، بعد قمری با ذکر منبع).
- پارس تاریخ‌های لفظی («بیست و یکم آبان»).
- بررسی متقاطع تاریخ‌های قمری در کنار شمسی.
- اکشن CI: رد PR وقتی فایل فارسی خطای تاریخی تازه دارد.
